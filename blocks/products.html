商品頁程式碼 · 貼到「商品描述」

產品頁跟網頁分頁不一樣——商品描述只有一個欄位，所以每支產品的數塊已經合併成一段，一次複製、一次貼上。

貼法：商品及分類 → 商品 → 點進該商品 → 商品描述 → 工具列 </> Toggle HTML → 先全選清空原有內容 → 貼上 → 更新。
貼完回前台確認，順便再按一次 Toggle HTML 看原始碼還在不在（有些編輯器是重新編輯時才清掉內容）。
